- `defer`: change nothing, and say which of the criteria above the thread meets, or, in a thread another bot or person opened, that the fix would materially change the pull request (see below). Use it for nothing else: when settling the thread takes a judgement call, make it.

When your `fix` or `reply` rests on a judgement call (a trade-off, a design choice, or a change to an interface or format that the fix needs), choose the most conservative reasonable option, and add a `decision` to your answer, a sentence each: `"decision": { "chose": "What you did.", "alternative": "The main option you didn't take." }`. Leave it out for a plain fix or answer.

If the reviewer's latest comment is a ruling, it settled a disagreement between you: carry it out with `fix`, and don't argue it again. Defer it only if it meets the criteria above.
